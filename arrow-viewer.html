使い方と注意事項
基本操作
  1. .arrow / .arrows / .ipcファイルを1つまたは複数選択・ドロップします。
  2. ファイル情報で形式、行数、レコードバッチ、辞書、メタデータを確認します。
  3. スキーマをTree / Rawで確認し、データをTable / Recordで表示します。
  4. 現在ページをCSVとしてコピーまたは保存できます。
プライバシー
読み込んだファイルはブラウザー内だけで処理します。このアプリから外部サーバーへ送信しません。
注意事項
  • 現在のバージョンはArrow IPC File / Streamを対象にします。Featherは正式対応形式として案内しません。
  • LZ4 / ZSTDで圧縮されたIPC body bufferは現在のバージョンでは未対応として案内します。
  • 閲覧専用です。元のArrow IPCファイルを書き換えません。
  • CSV出力はファイル全体ではなく現在ページが対象です。
配布用HTMLは実行時の外部通信を必要とせず、ローカルファイルとして直接開けます。
